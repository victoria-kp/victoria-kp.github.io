  • AI-QuantumMechanic

    The source code is available on GitHub.

    AI-QuantumMechanic is a prototype LLM agent that solves graduate-level quantum mechanics problems through tool orchestration rather than memorization. Instead of generating equations directly, the agent delegates every symbolic and numerical computation to verified tools and references results through opaque registry keys it cannot forge, ensuring a verifiable chain of provenance for each derivation step.

    Architecture:

    • Three-node LangGraph state machine powered by Anthropic's Claude Sonnet: reasoning → tool execution → validation.
    • The reasoning node decides whether to invoke a tool or present a final answer; the tool execution node dispatches to the appropriate handler; the checker node validates the result and provides feedback for retries if needed.

    Tool Suite (20+ operations):

    • Symbolic math (SymPy): algebra, calculus, ODE solving with automatic boundary-condition handling, quantum operators, Fourier transforms, and special-function evaluation.
    • Numerical compute (SciPy/NumPy): root finding, ODE integration with automatic higher-order-to-first-order system decomposition, quadrature, and wavefunction normalization.
    • Equation catalog: a read-only reference of standard physics equations whose raw expressions are hidden from the LLM and accessible only through tool calls.
    • Plotting: Matplotlib-based generation of publication-quality wavefunction and probability-density figures.

    Anti-Hallucination Mechanism:

    • Every tool result is stored in a dual registry (symbolic expressions and numerical arrays) under opaque, auto-incrementing keys. The agent must reference these keys—not raw formulas—when calling subsequent tools.
    • A strict input validator rejects any compound expression the LLM tries to inject directly, guaranteeing that every expression in the derivation has a verifiable computational origin.

    Validation System:

    • Expression sourcing: verifies that every mathematical expression in the final answer traces back to a tool result.
    • Normalization: confirms wavefunctions satisfy ∫|ψ|² = 1 across multiple coordinate systems.
    • Physical sanity: checks energy signs, probability non-negativity, and energy-level ordering.

    Demonstrated Capabilities:

    • Infinite square well — fully analytical solution with boundary conditions and normalization.
    • Quantum harmonic oscillator — analytical solution with special functions and quantization conditions.
    • Finite square well — hybrid analytical/numerical approach with boundary matching and numerical integration.

    Technologies: LangGraph, Anthropic SDK (Claude Sonnet), SymPy, SciPy, NumPy, Matplotlib, pytest.

  • FlavorBuilder

    The package is available on PyPI and GitHub.

    FlavorBuilder is a unified Python framework for model building with finite flavor symmetries in particle physics. It integrates group-theory computations via GAP with model-building tools for constructing and analyzing flavor models. This package serves as a core component supporting our work in arXiv:2506.08080 [hep-ph]. It contains the subpackages PyDiscrete and Model2Mass.

    PyDiscrete is a Python reimplementation of the Mathematica package Discrete that enables group-theory computations via GAP. It extracts group properties and character tables, and computes Kronecker products and Clebsch–Gordan coefficients. See the tutorial notebook TutorialPyDiscrete.ipynb included in the GitHub repository for more details.

    Model2Mass provides symbolic and numerical tools for constructing Lagrangians, deriving mass matrices, and computing phenomenologically relevant quantities for BSM flavor models with finite flavor symmetry.
