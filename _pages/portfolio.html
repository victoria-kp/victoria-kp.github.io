  • AI-QuantumMechanic

    The source code is available on GitHub.

    AI-QuantumMechanic is a prototype LLM agent that solves graduate-level quantum mechanics problems through tool orchestration rather than memorization. Instead of generating equations directly, the agent delegates every symbolic and numerical computation to verified tools and references results through opaque registry keys it cannot forge, ensuring a verifiable chain of provenance for each derivation step.

    Architecture:

    • Three-node LangGraph state machine powered by Anthropic's Claude Sonnet: reasoning → tool execution → validation.
    • The reasoning node calls Claude with the full conversation history and tool definitions; it either requests a tool call or presents a final answer.
    • The tool execution node dispatches to one of four tool handlers and routes back to reasoning.
    • The checker node runs three independent validators; on failure it returns actionable feedback and retries (up to 2), with a sanitizer fallback as graceful degradation.

    Tool Suite (20+ operations):

    • Symbolic math (SymPy): algebra, calculus, ODE solving (with automatic boundary-condition handling for both finite-domain and normalizable solutions), commutators, time evolution, Fourier transforms, and special-function evaluation (Hermite, Laguerre, spherical harmonics, parabolic cylinder D).
    • Numerical compute (SciPy/NumPy): root finding (brentq, fsolve), ODE integration (solve_ivp, solve_bvp) with automatic higher-order-to-first-order system decomposition, quadrature, and wavefunction normalization.
    • Equation catalog: a read-only reference of 14 standard physics equations (Schrödinger equations, potentials, operators, eigenvalues). Raw expressions are hidden from the LLM and accessible only through tool calls, adding another anti-hallucination layer.
    • Plotting: Matplotlib-based generation of publication-quality wavefunction and probability-density figures.

    Anti-Hallucination Mechanism — Opaque Registry Keys:

    • Every tool result (symbolic or numerical) is stored in an in-memory registry under auto-incrementing keys (expr_1, expr_2, … for symbolic; data_1, data_2, … for numerical arrays).
    • The agent can read expression strings for reasoning, but must pass opaque keys—not raw formulas—when calling the next tool. A strict regex rejects any compound expression the LLM tries to inject as a substitution value.
    • This dual-registry design keeps large objects out of the LLM context while guaranteeing that every expression in the derivation has a verifiable computational origin.

    Validation System (Three Independent Checkers):

    • Expression sourcing: verifies that every mathematical expression in the final answer traces back to a tool result, using exact substring matching and chunk-overlap detection.
    • Normalization: confirms wavefunctions satisfy ∫|ψ|² = 1, supporting multiple coordinate systems (Cartesian, spherical, cylindrical, polar) with appropriate integration weights.
    • Physical sanity: checks bound-state energy signs, probability non-negativity, and energy-level ordering (E₀ < E₁ < E₂).

    Demonstrated Capabilities:

    • Infinite square well — fully analytical: symbolic ODE solving with finite-domain boundary conditions, eigenvalue extraction, and normalization.
    • Quantum harmonic oscillator — analytical with special functions: normalizable boundary conditions, asymptotic analysis, parabolic cylinder D functions, and quantization-condition extraction.
    • Finite square well — hybrid analytical/numerical: symbolic setup per region, boundary matching, transcendental root finding, numerical ODE integration, and wavefunction normalization.

    Technologies: LangGraph, Anthropic SDK (Claude Sonnet), SymPy, SciPy, NumPy, Matplotlib, pytest.

  • FlavorBuilder

    The package is available on PyPI and GitHub.

    FlavorBuilder is a unified Python framework for model building with finite flavor symmetries in particle physics. It integrates group-theory computations via GAP with model-building tools for constructing and analyzing flavor models. This package serves as a core component supporting our work in arXiv:2506.08080 [hep-ph]. It contains the subpackages PyDiscrete and Model2Mass.

    PyDiscrete is a Python reimplementation of the Mathematica package Discrete that enables group-theory computations via GAP. It extracts group properties and character tables, and computes Kronecker products and Clebsch–Gordan coefficients. See the tutorial notebook TutorialPyDiscrete.ipynb included in the GitHub repository for more details.

    Model2Mass provides symbolic and numerical tools for constructing Lagrangians, deriving mass matrices, and computing phenomenologically relevant quantities for BSM flavor models with finite flavor symmetry.
